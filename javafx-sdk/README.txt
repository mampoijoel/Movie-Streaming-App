Unzip the JavaFX SDK here so that this file sits next to a folder called "lib":

  javafx-sdk/lib/javafx.base.jar   (and the other javafx.*.jar files + native libs)

Download: https://gluonhq.com/products/javafx/  ->  JavaFX 21 (LTS), pick your OS, type "SDK".
After unzipping you get a folder like javafx-sdk-21.0.x/ . Copy ITS CONTENTS (bin, lib, ...) into this folder.
This folder is git-ignored (the SDK is large); every group member does this once.
